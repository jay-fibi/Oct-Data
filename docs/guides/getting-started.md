# Getting started

Open `index.html` in a web browser, then click **Say hello** to update the message.
No installation or build step is required.

## Files

- `index.html`: page markup referencing the JavaScript and stylesheet.
- `script.js`: button click behavior.
- `styles.css`: layout, colors, and button styling.
- `config.json`: example project metadata and asset paths; not loaded by the page.
- `docs/guides/getting-started.md`: this nested documentation file.
