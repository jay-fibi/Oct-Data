# FreshMart Grocery Store Website

A simple, responsive static website for **FreshMart Grocery Store** built with plain HTML, CSS, and JavaScript.

## Features

- **Product Catalog**: Browse 12 everyday grocery items across Produce, Dairy, Bakery, Beverages, and Pantry categories.
- **Category Filtering & Live Search**: Filter items by category or search by keyword in real time.
- **Interactive Shopping Cart**: Add/remove items, adjust quantities, and view automatic subtotal, free-delivery eligibility (free over $35), and order total calculation.

## Getting Started

Open `index.html` directly in any web browser, or serve the folder locally:

```bash
cd grocery-store
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
