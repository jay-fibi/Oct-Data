# Jacks stocks

`Jacks stocks.apk` is the installable **1.0.1 (version code 2)** debug build of the Android NSE portfolio tracker. Requires Android 8.0/API 26 or newer.

This is a debug-signed testing build, not a production-signed release. It contains no seeded portfolio. Review screenshots use explicitly labelled fictional transactions. Back up an existing ledger before installing; updates require a compatible signing key.

Source and validation documentation are in the repository's `jacks-stocks` directory. Absolute paths in that documentation identify the original validation machine; use your local checkout path when running commands elsewhere.
